# TruAD Dashboard Backend

This is the Backend for the TruAD dashboard.

## Technologies used

- NodeJS
- ExpressJS
- MongoDB


## Installation

Install my-project with npm

```bash
$ git clone https://github.com/mangeshtruad/truAD-backend
$ cd /truAD-backend
$ npm install
$ npm start
```
